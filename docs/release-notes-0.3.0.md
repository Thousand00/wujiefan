WujieFan 0.3.0 —— 机械革命无界14+ (ARN39P-TF) 风扇转速监视与强冷控制

从 EC 读两颗风扇的转速和 CPU 温度，并可一键把风扇拉到满转。

## 0.3.0 新增什么

**风扇强冷模式**：界面多一个勾选框，两档可选 ——

| 档位 | 效果 |
| --- | --- |
| 自动（默认） | 由 EC 固件按温度调，日常 3000~4200 RPM |
| 强冷 | 两个风扇满转，约 5700 RPM，重载时温度可低 10~14°C |

只有这两档，**不提供任意调速、也绝不降速**。原因很实在：EC 一旦被切到手动模式，即使控制进程被 `taskkill /F` 杀掉也不会自己回退，标志与 PWM 值原样留着。允许降速，就等于允许把机器留在「比固件自己认为安全还低」的转速上。只往上升，最坏结果是吵，不会过热。

配套的五条安全路径：启动时按设置归一化 EC 状态、正常退出时恢复自动、注销/关机时恢复自动、92°C 持续 3 秒看门狗强制恢复、托盘右键「恢复自动风扇」。

**其余修正**

- 开机自启改用两跳启动器链路，修掉了「计划任务启动后托盘图标不出现」（0.2.0）
- 修掉 15 处缺陷：供数永久失效、自启动升级不生效、schtasks 编码、互斥体全生命周期持锁、句柄泄漏、进程调用死锁等

## 两个包选一个

| 包 | 大小 | 前提 |
| --- | --- | --- |
| `WujieFan-0.3.0-win-x64.zip` | 228 KB | 需装 .NET 8 桌面运行时 |
| `WujieFan-0.3.0-win-x64-portable.zip` | 91 MB | 免运行时，解压即用 |

两个包都是解压后直接跑 `WujieFan.exe`，**必须以管理员身份运行** —— EC 读写走 PawnIO 内核驱动，设备权限只放行 Administrators 与 SYSTEM。包里除了 `WujieFan.exe` 还有一个 `WujieFanLauncher.exe`，**两者必须放在一起**，开机自启靠它中转提权。

## 它能做什么

- 实时显示 Fan1（CPU 侧）、Fan2（GPU 侧）转速，以及 CPU 温度
- 强冷模式（0.3.0 新增）
- 托盘常驻：点 × 收进托盘，双击托盘图标、右键菜单或再启动一次都能唤回窗口
- 开机自启（登录时经 UAC 以管理员身份拉起，可在界面勾选）
- 把读数发布到 `AIDA64_SensorValues` 共享内存，供 RTSS OverlayEditor 作为数据源引用

## 接入 RTSS 叠加层

程序运行后，`tools\add-wujie-layers.py` 会往布局文件里加两个可拖动图层（`Fan1 xxx RPM` / `Fan2 xxx RPM`）。改完必须重启 RTSS.exe，布局没有热重载。

排查顺序：先 `tools\read-aida.py` 看共享内存里有没有数，再 `tools\peek-overlay.py --full` 看 RTSS 有没有把宏替换成数字。

## 硬性前提

- 机型：MECHREVO 无界14+，型号 ARN39P-TF（Ryzen 7 7840HS）。程序启动会校验，不匹配直接拒绝运行。
- EC 版本：2.12。不同 EC 版本寄存器布局可能不同。
- 需要 [PawnIO](https://pawnio.eu/) 已安装（提供 `PawnIOLib.dll` 与内核驱动）。

## 已知限制

- 只支持 64 位 Windows
- 主程序被强杀时，EC 会停在手动满转不回退（吵，但不超温）。再次启动程序会自动归一化；也可用托盘右键「恢复自动风扇」手动恢复。软重启不清 EC 的 RAM 状态，只有断电冷启动才复位。
  （订正：本文件早期版本写的 `WujieFan.exe --fan-auto` 从未实现，主程序只认 `--tray`。）
- 布局脚本的默认目标是桌面上的 `default.ovl`；改过路径需自行指定
- `PositionX` 不是绝对像素，负值向右、绝对值过大图层会静默消失
