# WujieFan 0.4.0

界面按设计稿重做。读数、供数、自启动、风扇控制的行为与 0.3.0 完全一致。

## 界面

- 深色圆角无边框窗口（432 宽，按 DPI 等比放大），标题栏、最小化、关闭全部自绘
- 三列数据卡：Fan1 (CPU) / Fan2 (GPU) / CPU 温度；小圆点区分「正常 / 停转 / 读数不可信」
- 三行整行可点的开关：开机自动启动 / 向 RTSS 提供数据 / 强冷模式
- 强冷那行右侧的徽章显示**从 EC 回读的真实状态**（自动 / 强冷 / 异常标志），切换失败立刻回滚
- 所有提示框换成深色自绘弹窗，托盘菜单也换成深色渲染器

## 两个包

| 包 | 大小 | 前提 |
|---|---|---|
| `WujieFan-0.4.0-win-x64.zip` | 237 KB | 需 .NET 8 桌面运行时 |
| `WujieFan-0.4.0-win-x64-portable.zip` | 91 MB | 免运行时，解压即用 |

两个 exe（`WujieFan.exe` 与 `WujieFanLauncher.exe`）必须放在同一目录，否则开机自启会报「缺少启动器文件」。

## 能力

- 从 EC 读两个风扇转速与 CPU 温度，1 秒刷新
- 作为 RTSS OverlayEditor 的标准可拖动图层显示（经 AIDA64 共享内存通道）
- 开机自启（两跳启动器链路，托盘图标正常显示）
- 风扇强冷模式：自动 / 强冷两档，只升不降

## 硬性前提

- Windows x64 + 管理员权限（PawnIO 驱动只对 SYSTEM 与 Administrators 开放）
- 仅支持 MECHREVO 无界14+（ARN39P-TF）+ EC 2.12；机型或固件不符时程序直接拒绝
- RTSS 7.3.x（若要叠加层图层）

## 已知限制

- 强冷模式下主程序被强杀，EC 会停在满转（吵，但不会过热）；下次启动会自动归一化
- 软重启不复位 EC 手动模式，只有关机冷启动才回到自动
