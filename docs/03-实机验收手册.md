# WujieFan 实机验收手册（0.4.1）

这份手册只做一件事：**在你这台真机上，把"写 EC"那条链路验一遍**，跑完你能看懂结论，失败了知道把哪段发回来。

不需要装开发环境，不需要双击任何脚本。只需要一个**管理员 PowerShell 窗口**外加一条粘贴。

---

## ⚠️ 先读风险提示

`--fanmode-live` 这一项会**真的去写 EC、把两个风扇拉到最高转速**。

- 跑的时候风扇会明显变吵，约 **15 秒**（满转 3 秒 + 回落 4 秒 + 前后采样），**这是正常的**，不是故障。
- 程序跑完会自动把风扇交还"自动"模式，结束前会打印一行 `[恢复] ... / 自动`。
- **中途按 Ctrl+C 打断，恢复那一步不会执行**。风扇会一直停在满转。此时**必须手动打开一次 WujieFan，把强冷开关关掉（或重启机器）**，否则它会一直吵下去。不会烧机器，但会一直满转。
- 跑之前请**先退出正在运行的 WujieFan**（托盘图标右键退出），避免两个进程同时碰 EC。

其余两项（`--autostart-cn` / `--autostart-upgrade`）只碰计划任务，不碰 EC，没有这个风险。

---

## 前提（不符合会直接报错，不会硬跑）

1. **必须是管理员窗口**。EC 读写走 PawnIO 内核驱动，设备权限只放行 Administrators 与 SYSTEM，普通窗口一定会失败。
2. **机器必须是 MECHREVO 无界14+（ARN39P-TF）+ EC 2.12**。机型不符程序会拒绝，这是设计如此。
3. **PawnIO 驱动已安装**（装过 WujieFan 并成功跑起来过，就有了）。
4. **要有 .NET 8 运行时**。验收程序是框架依赖的，便携版 WujieFan 包里不含运行时。

---

## 怎么开管理员 PowerShell

开始菜单搜 `PowerShell` → 右键 → **以管理员身份运行**。窗口标题栏应出现「管理员」字样。

先粘这一段做自检，**四项都必须是 OK**：

```powershell
$admin = ([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)
"1) 管理员会话      : $(if($admin){'OK'}else{'否 —— 关掉重开，必须右键以管理员身份运行'})"
$exe = 'E:\WORKS\RTSS-0\tests\EcReadSmoke\bin\Release\net8.0-windows\EcReadSmoke.exe'
"2) 验收程序存在    : $(if(Test-Path $exe){'OK'}else{"找不到 $exe"})"
"3) .NET 8 运行时   : $(if($(dotnet --list-runtimes 2>$null) -match 'Microsoft\.NETCore\.App 8\.'){'OK'}else{'未找到，需装 .NET 8 运行时'})"
"4) PawnIO 驱动     : $(if((Get-Service PawnIO -ErrorAction SilentlyContinue).Status -eq 'Running'){'OK'}else{'未运行'})"
```

> 路径按你这台机器的实际情况写死在这里了，不要自己改。如果第 2 项不是 OK，说明这份验收程序没编译出来，先别往下跑，直接告诉我。

## 一条命令跑完三项

确认上面四项全 OK 后，**整段复制粘贴**，回车。全程约 20 秒。

```powershell
$exe = 'E:\WORKS\RTSS-0\tests\EcReadSmoke\bin\Release\net8.0-windows\EcReadSmoke.exe'
$log = Join-Path ([Environment]::GetFolderPath('Desktop')) ("wujiefan-verify-{0}.txt" -f (Get-Date -Format 'yyyyMMdd-HHmm'))
"日志会存到: $log" | Tee-Object -FilePath $log

"`n===== ① 风扇强冷实机切换 =====" | Tee-Object -FilePath $log -Append
& $exe --fanmode-live 2>&1 | Tee-Object -FilePath $log -Append
$rc1 = $LASTEXITCODE

"`n===== ② 中文路径开机自启 =====" | Tee-Object -FilePath $log -Append
& $exe --autostart-cn 2>&1 | Tee-Object -FilePath $log -Append
$rc2 = $LASTEXITCODE

"`n===== ③ 自启动升级路径 =====" | Tee-Object -FilePath $log -Append
& $exe --autostart-upgrade 2>&1 | Tee-Object -FilePath $log -Append
$rc3 = $LASTEXITCODE

"`n===== 结论 =====" | Tee-Object -FilePath $log -Append
@(
  [pscustomobject]@{ 项目='① 强冷实机切换'; 退出码=$rc1; 结论=$(if($rc1 -eq 0){'通过'}else{'失败'}) }
  [pscustomobject]@{ 项目='② 中文路径自启'; 退出码=$rc2; 结论=$(if($rc2 -eq 0){'通过'}else{'失败'}) }
  [pscustomobject]@{ 项目='③ 自启动升级';  退出码=$rc3; 结论=$(if($rc3 -eq 0){'通过'}else{'失败'}) }
) | Format-Table -AutoSize | Tee-Object -FilePath $log -Append

"`n残留检查（三项都应为 空/False）:" | Tee-Object -FilePath $log -Append
"  测试任务 WujieFanCnTest      : $(schtasks /Query /TN WujieFanCnTest 2>$null | Select-String 'WujieFanCnTest')" | Tee-Object -FilePath $log -Append
"  测试任务 WujieFanUpgradeTest : $(schtasks /Query /TN WujieFanUpgradeTest 2>$null | Select-String 'WujieFanUpgradeTest')" | Tee-Object -FilePath $log -Append
"  测试目录 E:\测试 是否残留     : $(Test-Path 'E:\测试')" | Tee-Object -FilePath $log -Append
```

跑完桌面会多一个 `wujiefan-verify-日期时间.txt`。**把最后那张表，加上日志文件，一起发回来**就行。

> 风扇是否已经交还自动，看 ① 段倒数第二行的 `[恢复] ... / 自动`（它紧挨在 `结果:` 那行上面）。这行是程序自己打的，比事后猜可靠。

## 三项分别在验什么，怎么判断

### ① `--fanmode-live` —— 强冷到底是不是真的能拉满再回落

这一项回答的是最关键的问题：**程序说"已切强冷"，EC 里是不是真的切了**。之前所有结论都是"读回来是强冷"，但"读数到位"和"转速真的上去了"是两回事。

**通过长这样**：

```
=== 风扇两档控制 ===
切换前实际模式: 自动
[PASS] SetMode(StrongCool): ... / 强冷
[PASS] 强冷回读标志: 强冷
  强冷采样: 5xC  Fan1 5xxx RPM  Fan2 5xxx RPM
  3 秒后: 5xC  Fan1 5xxx RPM  Fan2 5xxx RPM
[PASS] 强冷转速确实拉高: Fan1 xxxx / Fan2 xxxx (期望都 > 4500)
[PASS] SetMode(Auto): ... / 自动
[PASS] 恢复自动后的标志: 自动
  恢复 4 秒后: 5xC  Fan1 3xxx RPM  Fan2 4xxx RPM
[PASS] 自动模式转速已回落: Fan1 xxxx / Fan2 xxxx (期望都 < 5200)
[恢复] ... / 自动
结果: 通过 6 / 失败 0
```

关键看三处：强冷时两路都 **> 4500**（满转约 5600～5700）；回落时两路都 **< 5200**；最后一行 `结果: 通过 6 / 失败 0`。

**失败长这样**：出现任何 `[FAIL]`，或末行是 `结果: 通过 5 / 失败 1` 之类，或退出码非 0。最要紧的是**卡在强冷不回落**——如果连 `[恢复]` 那行都没有、风扇一直吵，立刻手动开 WujieFan 关掉强冷。

**发回来什么**：从 `===== ① ...` 到下一个 `=====` 之间的**全部输出**，特别是所有 `[FAIL]` 行和 `[恢复]` 那行。

---

### ② `--autostart-cn` —— 中文路径下计划任务能不能建对

这一项验的是编码问题：计划任务里存的是 exe 路径，中文路径在 `schtasks` 里很容易被写坏，坏的后果是"勾了开机自启，重启后没反应"。

它会临时建一个叫 `WujieFanCnTest` 的任务、建一个 `E:\测试` 目录放两个空文件，用完自己删干净——**不会留下任何东西，也不会真的启动程序**。

**通过长这样**：

```
=== 中文路径自启动测试 ===
目标 exe = E:\测试\WujieFan.exe
1. Enable -> ok=True
2. IsEnabled (中文路径) = True  OK
3. 任务里的 Command = E:\测试\WujieFanLauncher.exe
4. 与启动器路径一致 = True  OK
5. Disable -> ok=True, 之后 IsEnabled = False  OK

结果: 通过
```

关键看第 2 项是 `True` 且带 `OK`、第 4 项是 `True` 且带 `OK`、末行 `结果: 通过`。

**失败长这样**：第 2 项出现 `FAIL 自启动勾选会回弹`，或第 4 项出现 `FAIL 编码被破坏`，或第 5 项出现 `FAIL`。

**发回来什么**：`===== ② ...` 那一段全部输出（就十几行）。

---

### ③ `--autostart-upgrade` —— 升级时能不能把旧任务改对

这一项验的是"从老版本升上来"的场景：老版本建的计划任务有两个毛病（不允许拔电源启动、72 小时后被强制结束），还会以最高权限直接启动主程序导致托盘图标不出现。**升级时必须被自动改写**，否则老用户会一直踩。

它会故意造一份"老版本"的任务定义，再让程序去升级它，用完删掉。

**通过长这样**：

```
=== 自启动升级路径测试 ===
1. 旧定义 DisallowStartIfOnBatteries = true  OK 旧缺陷已复现
   旧定义 ExecutionTimeLimit = ...  OK 旧缺陷已复现
   旧定义 IsUpToDate = false : OK 会触发自动重写
2. Enable -> ok=True
3. IsEnabled = True  OK
4. 重写后 DisallowStartIfOnBatteries=false : OK
   StopIfGoingOnBatteries=false           : OK
   ExecutionTimeLimit=PT0S (无限)         : OK
   RunLevel=LeastPrivilege                 : OK
   执行 WujieFanLauncher.exe              : OK
5. 重写后 IsUpToDate = True  OK

结果: 通过
```

关键看第 4 组五行**全是 `OK`**、第 5 项是 `True` 且带 `OK`、末行 `结果: 通过`。

**失败长这样**：第 4 组任何一行出现 `FAIL`（例如 `FAIL 升级后仍不能拔电源启动`、`FAIL 升级后仍直指主程序`），或第 5 项 `FAIL 每次启动都会再跑一遍 schtasks`。

**注意**：如果第 1 步打印 `0. 造旧任务失败`，那是权限不够或计划任务服务异常，不是程序缺陷——把那段发回来即可。

**发回来什么**：`===== ③ ...` 那一段全部输出。

## 如果整条命令就跑不起来

| 现象 | 意思 | 怎么办 |
|---|---|---|
| `无法加载文件 ... 因为在此系统上禁止运行脚本` | 只影响 `.ps1` 脚本；本手册的命令是直接粘贴的，不该出现 | 把窗口里完整红字发我 |
| `找不到 WujieFan.Core.dll` / `You must install .NET` | 验收程序缺配套文件或没有 .NET 8 运行时 | 发我截图，别自己装东西 |
| `打开设备失败: ...` 或 `拒绝访问` | 不是管理员，或 PawnIO 驱动没起来 | 确认标题栏有「管理员」，重跑自检 4 项 |
| 三个 `[FAIL]` 全挂 | 通常是环境问题而非代码问题 | 把整份日志发我，先别下结论 |
