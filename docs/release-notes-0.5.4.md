# v0.5.4 — 审计修复

这一版没有新功能。第二轮全面审计在同一个工作区快照上跑出五份报告，其中一批问题
属于「程序告诉你成功了，其实没有」。这个版本把它们修掉，并把已经改好但一直没提交的
修复正式发出去。

## 修掉的最要紧一条：强冷可能报成功而风扇没满转

强冷模式的写入顺序是「PWM1 → PWM2 → 标志1 → 标志2」，但校验只回读了两个模式标志
（`0x021F` / `0x029F`），**从来没有回读手动 PWM 值**（`0x021E` / `0x029E`）。

如果 PWM 写入被 EC 静默丢弃、而标志写成功，EC 会采信上一次残留的 PWM 值 —— 风扇可能
只有低速甚至不动，程序却在状态栏和托盘气泡里报「强冷已开启，两个风扇满转」。这是
最坏的一类错误：用户因为看到"已开启"而不再检查。

现在写完会回读两个 `ManualPwm` 是否都等于 `PwmMax`（184）。不等就按「状态不确定」
报出来，并明确写出回读到的值，让用户自己看一眼当前转速确认。

## 关闭强冷失败被报成成功

热键切换曾经用「意图是否等于目标」反推成败。关强冷失败时，失败分支会把意图清成
`false`，而目标「自动」对应的判断也是 `false` —— 两边相等，于是失败被当成成功，
托盘弹出「已交还自动模式」，实际风扇还在手动满转。

现在 `SetMode` 返回真实的 `FanModeResult`，调用方按结果判成败，不再反推。

## 退出时分裂状态没有被交还

退出判据原本是「当前模式 `== Auto` 才跳过交还」。但 `Mixed`（一个风扇手动、一个自动）
正是上一次写了一半留下的分裂残留，它不等于 `Auto`，所以现在会被交还；判据改成
`!= Auto`。同一个道理，`RestoreAuto` 在设备没打开时会明确说「没能交还」，而不是
报一句「已交还自动模式」。

## 其它修复

- **拿不到 EC 锁时不再谎报状态**：`ReadModeState` 返回 `Unknown` 而不是硬读。这个结果
  会被拿去决定退出时要不要交还，锁外硬读可能误判成"不用收手"。
- **机型匹配改精确相等**：原来用子串包含，`WUJIE 14` 会命中 `WUJIE 14 Pro`，等于把没验证
  过的机型放进白名单。
- **强行读取改成只读**：`ForceUnsupported` 现在只解锁观察，不允许写 EC。读错顶多显示错
  转速，写错是把未知机器的寄存器改成某个具体值。
- **`EcMutex` 记线程**：`_owned` 只存句柄，无法判断"是不是当前线程持有"。改成
  `(句柄, 线程 ID)`，`Release` 也按线程判定。
- **自动重连退避**：设备持续失败时原本每秒重建设备 + 每秒重绘整窗。现在从 2 秒起翻倍，
  封顶 30 秒，成功一次清零。
- **设置保存失败即回滚**：`Save()` 失败后原来会留下与磁盘不一致的内存对象，之后任意一次
  保存就把上次失败的值悄悄落盘。现在还原 `SchemaVersion` 与 `ForceUnsupportedConfirmedAt`。
- **自启查询补第三态**：`schtasks` 超时或起不来时，原来被当成"本来就没有自启动项"并报
  成功。现在区分「有 / 无 / 查不到」，查不到时拒绝操作并说明原因。
- **完整性校验非通过即不进后台**：删掉 `WujieFan.integrity.json` 原来仍能 `--tray` 常驻。
  现在只要校验结果不是 `Verified` 就剥掉 `--tray`。
- **`ui.log` 加 64 KB 轮转**：原来是无限增长。
- **发布脚本先过门禁**：`make-release.ps1` 打包前会调 `verify.ps1 -FailOnSkip`，失败直接停。
- **`_timer.Tick` 加兜底**：定时器回调里任何未预期异常都不再冒到线程级异常处理。
- **RPM 显示与 RTSS 一致**：界面不再显示 `>9999`，改为显示真实数字，与 overlay 相同。
- **温度未知时保留节点、value 留空**：原来整块省略 `<temp>`，RTSS 会继续显示上一次成功
  读到的温度。温度是过热保护唯一的安全信号，显示过期数字比显示空白危险。
- **剩余 3 处 `Save()` 判返回值**：退出、强行读取、恢复机型校验失败时写 `ui.log` 留痕。
- **热键切换按可见状态取反**：改用勾选框而不是内部意图，用户按一下的结果与自己看到的一致。

- `dotnet build WujieFan.sln -c Release` → 0 警告 0 错误。
- 单测 **222/222**（新增 1 条：温度未知时节点保留、`value` 为空）。下限从 218 上调到 222。
- `pwsh tools/verify.ps1` → 5/5 全过，`EXITCODE=0`；`autostart-test` 6/6；XML 契约三源
  `WUJIE_FAN1=1111` / `WUJIE_FAN2=2222` / `WUJIE_CPUT=33`（227 字节）。

人手按键也未做对照实验。
