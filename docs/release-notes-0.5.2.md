# v0.5.2 — 文档版本

这个版本没有任何代码改动，只重写 README 并删除过时截图。

## README 重写

0.5.1 及以前的 README 是多年累积出来的：功能清单和变更日志混在一起、同一件事在三个地方各说一遍、还带着版本标注（「0.3.0 新增」「0.4.0 重做」）——每发一版这些标注就过期一次。

这次从头写，结构按"读到的人需要什么"排：

它解决什么问题 → 下载 → 使用 → 设置 → 风扇控制 → 界面 → 排查 → 目录 → 构建 → 前提与风险 → 文档 → 许可。

具体做的取舍：

- **不放截图**。原来的截图都是 0.4.0 的样子：0.5.0 加了设置界面、主面板也改过，那些图已经不准确了。用文字描述界面，不用担心随版本过期。
- **不留版本标注**。「0.3.0 新增风扇控制」这类句子改成描述现状，不再追述历史——历史在各版本的发布说明里。
- **下载表用 `<版本>` 占位**，不硬编码当前版本号。
- 删掉「现在的状态」表：那是功能清单，和下面各节重复。
- 三处「tools 不随包分发」合并成一处。

体积：262 行 / 15,165 B → 177 行 / 10,478 B。

## 顺带订正的两处错误

- **`--fan-auto` 从来不存在**。README 和 0.3.0 的发布说明都写过「`WujieFan.exe --fan-auto` 可手动恢复自动风扇」，但 `src/WujieFan/Program.cs` 从 0.3.0 加入风扇控制起就只认 `--tray`，这个参数从未实现过。恢复自动风扇的真实途径只有两条：托盘右键「恢复自动风扇」，或关掉重开。
- **docs/01 的目录树停在 0.4.1**。缺了 0.5.0 以来的 6 个 UI 文件、测试工程、CI 配置，入库文件数写 58（实际 89）。已按当前实际重写。
