风扇模式状态语义

FanModeState徽章文案语义色触发条件
Auto实际: 自动中性灰两路模式标志均为 0x00，EC 固件自主调速
StrongCool实际: 强冷成功绿两路标志均为 0xDC，手动 PWM 184 满转
Mixed实际: 异常标志警告橙两路标志不一致，或落在 0xA5 / 0xCC 等未知取值
Unknown（不显示文案）弱灰设备尚未打开或未完成首次回读

界面必须守住的安全边界

  • 强冷只升不降：仅提供自动 / 强冷两档，手动 PWM 184（100% 占空比，约 5700 RPM），不做降速档；允许慢于固件判断才是真正的过热风险。
  • 温度看门狗：强冷状态下连续 3 次采样达到 92°C 以上才自动交还 EC；编译、游戏加载这类单次尖峰不打断强冷。
  • 写入范围：仅强冷时写四个寄存器（两路手动 PWM + 两路模式标志），自动模式下程序只读 EC，不碰风扇曲线表、阈值与 NVRAM。
  • 残留归一化：退出、注销、重启前主动交还自动；下次启动按设置把 EC 拉回约定模式，不依赖上次进程退出得是否干净。
  • 采样间隔固定 1 秒展示（设置项 PollIntervalMs 允许 200~10000ms，但不暴露进界面）。

本稿性质说明

这是一套高保真静态原型：页面内转速、温度均为示例值（自动档取日常区间，强冷档取自实测截图），不连接真实 EC 与 PawnIO；开关只切换原型视觉状态，不写设置、不操作硬件。落地到 WinForms 或其他 UI 框架时，按上方控件映射表一一对应即可。
