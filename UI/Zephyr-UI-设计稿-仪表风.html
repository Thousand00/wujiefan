关于「数据卡下面那条条」：现有代码没有它

  • 现状：现有 DataCard.OnPaint() 只画卡片底、圆点、标签、大数字、单位，没有任何刻度条 / 进度条。上一版设计稿里那条是我自己加的装饰，代码里不存在，所以它不会动、也没有数据绑定。
  • 本稿处理：主界面默认不画这条，忠于现有控件。
  • 可选增强（要做才加，需改代码）：在 DataCard 底部画 3px 细条，风扇按 RPM/6000、温度按 °C/100 填充宽度，绑定每轮 FanSample 刷新；风扇青、温度橙。示意如下，编码实现者按此比例与色值画即可。

WinForms 落地注意（给编码实现者）

1. HighDpiMode = PerMonitorV2，布局坐标全部走 Dpi.Px() 手算，字体随 DPI 自动放大。 2. 无系统边框：FormBorderStyle.None，标题栏 / 最小化 / 关闭全自绘；关闭只收托盘不退出。 3. 数据卡沿用现有 DataCard 自绘：圆点 + 标签 + Consolas 大数字 + 单位，不要新增竖线； 刻度条仅在上文「可选增强」获批后才画，默认不画。 4. 勾选框沿用现有 ToggleRow：18×18 圆角 5 方形框，选中 Accent 青底 + 深色对勾， 不要换成圆形 toggle 轨道（那是另一种控件，本稿不改控件形态）。 5. 徽章永远画 EC 回读的真实模式：强冷=绿，异常=橙，自动=灰，未知=空； 勾选框状态只反映用户意图，徽章不跟随勾选。 6. 窗口底可铺 22px 网格暗纹（alpha 5%），仅装饰层，Pointer 不响应；GDI+ 里 辉光用 1px 浅色偏移叠加或省略 text-shadow，不要为发光引入图层。 卡片/按钮的微渐变、顶部高光、投影为装饰层，GDI+ 实现成本高时可全部省略， 回到纯色 Panel 即可，布局与色值不变。 7. 保存顺序（SettingsDialog→MainForm）：写内存 → Save 落盘 → _publisher.Apply() → ApplyHotKey() → 按 taskState Enable/Disable 计划任务；落盘失败回滚并弹 DarkDialog。 8. 强冷只升不降；过热保护、EC 写寄存器范围、残留归一化等安全逻辑一律不动，本稿只改外观。

界面必须守住的安全边界（与外观无关，不得因改版改动）

  • 强冷只升不降：仅自动 / 强冷两档，PWM 184（约 5700 RPM），不做降速档。
  • 温度看门狗：强冷下连续 N 次（默认 3）采样 ≥ 阈值（默认 92°C，可设 70–100）才自动交还 EC；单次尖峰不打断。
  • 写入范围：仅强冷写四个寄存器（两路 PWM + 两路标志），自动模式只读 EC。
  • 残留归一化：退出 / 注销 / 重启前主动交还自动；下次启动按设置拉回约定模式。
  • 采样间隔固定 1 秒展示（PollIntervalMs 250–10000 不暴露进界面）。

本稿性质说明

高保真静态原型，不连接真实 EC 与 PawnIO；示例读数为示意。落地时按控件映射表一一对应到现有字段， 行为逻辑、状态分支、安全边界完全沿用现版，本稿只提供视觉 token 与像素规格。
